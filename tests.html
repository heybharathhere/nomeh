Engine test suite

What this covers. Every pure engine: the bio-math (BMI, BMR, TDEE, calorie floors, macros, hydration, sweat rate, unit conversion), the natural-language log parser, and the analytics reducers. These run on the actual device, so a browser-specific difference in number or date handling shows up here rather than in your data.

Database, migration and backup-restore tests need a driven browser session and are not included — see "Known gaps" in the README rather than assuming they pass.
